# คู่มือการตั้งค่าระบบบันทึกและแชร์สถานะส่วนกลาง (Cloud Sync via Google Sheets)
### Customer (Salesforce) ในสังกัด ปข.6

---

## 🎯 ปัญหาที่ได้รับการแก้ไข
1. **กดรีเฟรชหรือปิดหน้าต่างแล้วข้อมูลไม่หายอีกต่อไป**: 
   - ระบบจะบันทึกสถานะลงในเบราว์เซอร์ (`LocalStorage`) ทันทีที่เลือกเปลี่ยนสถานะ
   - เมื่อรีเฟรชหน้าเว็บ หรือปิดคอมแล้วเปิดใหม่ ข้อมูลที่บันทึกไว้จะยังคงอยู่ครบ 100%
2. **แชร์ข้อมูลให้ทุกคนในสังกัดดูพร้อมกันได้จากทุกที่**:
   - ระบบรองรับการซิงค์ข้อมูลกับ **Google Sheets** ผ่าน **Google Apps Script**
   - เมื่อเจ้าหน้าที่คนใดเปลี่ยนสถานะ ข้อมูลจะถูกบันทึกส่งขึ้น Google Sheet และเพื่อนร่วมงานคนอื่นๆ จะเห็นข้อมูลอัปเดตตรงกันทันที

---

## 🚀 ขั้นตอนการติดตั้ง Google Apps Script (ทำเพียงครั้งเดียว 3 นาที)

### ขั้นตอนที่ 1: เปิด Google Sheet แหล่งข้อมูล
1. เปิด Google Sheet ที่ใช้จัดเก็บข้อมูลรายชื่อลูกค้า
2. ไปที่แถบเมนูด้านบน คลิก **"ส่วนขยาย" (Extensions)** &gt; เลือก **"Apps Script"**

### ขั้นตอนที่ 2: วางโค้ดระบบ
1. ในหน้าต่าง Apps Script จะมีไฟล์ชื่อ `Code.gs` ให้**ลบโค้ดเดิมทั้งหมดออก**
2. คัดลอกโค้ดจากไฟล์ [`google-apps-script.js`](./google-apps-script.js) (หรือกดปุ่มคัดลอกในหน้าต่าง "⚙️ ตั้งค่า Google Sheet" บนหน้าเว็บ) ไปวางใน `Code.gs`
3. กดปุ่ม **บันทึกโครงการ** (รูปแผ่นดิสก์ หรือกด `Ctrl + S`)

### ขั้นตอนที่ 3: ทำให้ใช้งานได้ (Deploy Web App)
1. คลิกปุ่มสีน้ำเงินมุมบนขวา **"ทำให้ใช้งานได้" (Deploy)** &gt; เลือก **"การนำไปใช้งานใหม่" (New deployment)**
2. คลิกไอคอนรูปเฟือง (⚙️) ข้างประเภท เลือก **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description)**: `Salesforce Status Cloud API`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` ⚠️ **สำคัญมาก ต้องเลือก "ทุกคน" เพื่อให้เพื่อนร่วมงานเครื่องอื่นบันทึกได้**
4. คลิกปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. หากมีหน้าต่างขออนุญาตสิทธิ์เข้าถึง ให้กดยินยอม (Authorize access)
6. ระบบจะแสดง **URL เว็บแอป (Web app URL)** (ลิงก์จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`) ให้คลิก **คัดลอก (Copy)**

### ขั้นตอนที่ 4: นำ URL มาใส่ในระบบหน้าเว็บ
1. เปิดหน้าเว็บระบบ Customer (Salesforce)
2. คลิกปุ่ม **"⚙️ ตั้งค่า Google Sheet"** (มุมขวาบน ข้างหัวข้อ)
3. วาง Web App URL ที่คัดลอกมาลงในช่อง **Google Apps Script Web App URL**
4. คลิกปุ่ม **"🔍 ทดสอบ"** เพื่อตรวจสอบการเชื่อมต่อ
5. คลิกปุ่ม **"💾 บันทึกและซิงค์"**

## 📊 ข้อมูลใน Google Sheet จะถูกจัดเก็บอย่างไร?
ระบบจะสร้างแท็บใหม่ชื่อ **`Status_Updates`** ใน Google Sheet ของคุณโดยอัตโนมัติ โดยมีคอลัมน์ดังนี้:
- **Row Index**: ลำดับแถวของข้อมูล
- **Account Name**: ชื่อลูกค้า
- **Province**: จังหวัด
- **Post Office**: ที่ทำการไปรษณีย์
- **Zip Code**: รหัสไปรษณีย์
- **Salesforce Status**: สถานะ (ดำเนินการแล้ว / กำลังดำเนินการ / ไม่สามารถดำเนินการได้)
- **Updated At**: วันและเวลาที่บันทึกล่าสุด
- **User / Source**: ที่มาของการบันทึก

## 💡 ฟีเจอร์เพิ่มเติม
- **Auto-Sync**: ดึงข้อมูลอัปเดตล่าสุดจากเพื่อนร่วมงานอัตโนมัติทุก 30 วินาที
- **ปุ่ม "ซิงค์ข้อมูล"**: กดดึงข้อมูลสถานะล่าสุดได้ทันทีทุกเวลา
- **ระบบสำรองข้อมูล (Backup JSON)**: สามารถดาวน์โหลดไฟล์สถานะทั้งหมดเก็บไว้ในคอมพิวเตอร์ หรือนำไปเปิดในเครื่องอื่นได้ในแท็บ "สำรองข้อมูล"
